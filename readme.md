# 道门

《道门》的在线阅读站与手稿仓库。

## 站点结构

- 首页：`index.html`，放作品简介、章节目录和后续卷目。
- 阅读页：`reader.html`，按章显示正文，支持上一章、下一章、目录跳转和阅读进度。
- 正文源：`道门/第一卷.md`，站点只把“第X章”形式的一级标题发布为章节。
- 大纲：`道门/大纲.md`，首页的“后续长卷”从这里读取。

## 写作方式

本地写作只维护 `道门/第一卷.md` 一个正文文件。新增章节时，用一级标题开头：

```markdown
# 第十六章 章节名
```

拆章时 `# 目录` 会被忽略，正文里的 `[返回目录](#目录)` 也不会显示。已发布章节的标题要写成 `# 第X章 章节名`，不要改成 `##`。未完成的章节可以用其他一级标题留在同一文件里，只要不是“第X章”形式，就不会出现在网站上。

## 本地预览

不能直接双击 `index.html`。浏览器在 `file://` 下不允许脚本读取 Markdown 文件，需要先起一个本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。

## 测试

```bash
npm test
```

测试覆盖已发布章节筛选、拆章、大纲解析、Markdown 渲染和 HTML 转义。

## 部署

推送到 `main` 分支后，由 GitHub Pages 发布仓库根目录。根目录的 `.nojekyll` 让 Markdown 文件按原文提供，不经过 Jekyll 转换。

## 目录说明

- `assets/`：样式、拆章逻辑和页面脚本。
- `道门/`：小说正文与全书大纲。
- `test/`：Node 内置测试。
- `admin/`：Decap CMS 入口。
